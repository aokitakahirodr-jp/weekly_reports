# 週刊・小児血液腫瘍ラジオ 2026-11-02 号

出典: PubMed（PMID 42960217 / 42944591 / 42960221）。医学的判断は原著をご確認ください。

**ナオ**: こんにちは、週刊・小児血液腫瘍ラジオ、2026年11月2日号です。進行役のナオです。

**マキ先生**: 解説役のマキ先生です。小児血液腫瘍が専門です。よろしくお願いします。

**ナオ**: 今週は、PubMedの新着から3本を深掘りします。白血病の層別化、横紋筋肉腫の二次がん、そして若年成人の白血病治療へのアクセスです。

**マキ先生**: はい。どれも日々の診療や長期フォローに関わる話題です。ただし、ここでの紹介は要点の整理ですので、必ず原著をご確認ください。

**ナオ**: まず1本目。ブラッド・ネオプラジア誌に載った、歴史的に高リスクとされてきた小児B前駆細胞性急性リンパ性白血病の論文です。PMIDは4296、0217です。

**マキ先生**: これは日本小児がん研究グループ、JCCGのALL-B12試験に登録された患者さんの事後解析です。KMT2A再構成型が28例、低二倍体が27例です。

**ナオ**: そもそも、なぜこの2つが高リスクとされてきたのですか。

**マキ先生**: どちらも従来は再発しやすい、あるいは移植を考慮する亜型とされてきました。ただ、現代のリスク適応治療では予後がどうなのか、はっきりしない部分がありました。

**ナオ**: 結果はどうでしたか。

**マキ先生**: 5年無イベント生存率と全生存率は、KMT2A再構成型で85.7%と89.3%、低二倍体で85.2%と85.2%でした。例数は少ないですが、思ったより良好です。ただし各亜型の中で経過はばらついていました。

**ナオ**: ばらつきというのは。

**マキ先生**: KMT2A再構成型では、プレドニゾロンへの反応が不良、あるいは測定可能残存病変、MRDが持続する場合、移植をしても再発リスクが高いと関連していました。一方で、MRDが低い範囲で消える方は、おおむね良好でした。低二倍体の中でも、いわゆる低二倍体の一部は移植なしで良い成績でした。

**ナオ**: つまり、亜型だけで一律に判断しないということですね。

**マキ先生**: その可能性が示唆されています。ただ後方視的な小規模解析なので、移植適応を変える根拠としては、前向きな検証が必要です。

**マキ先生**: 今日のTake Homeを3点。一つ、高リスクとされた亜型も内部は異質。二つ、KMT2A再構成型ではプレドニゾロン反応とMRDが再発リスクの手がかり。三つ、低二倍体の一部は移植なしでも良好で、早期反応が移植適応の見直しに役立つ可能性があります。

**ナオ**: 続いて2本目。キャンサー誌、2026年11月号掲載の、横紋筋肉腫の維持療法と二次がんの論文です。PMIDは4294、4591です。

**マキ先生**: 欧州小児軟部肉腫研究グループのRMS2005試験で、1633例を解析しています。高リスク例では、低用量シクロホスファミドとビノレルビンの維持療法が生存を改善しました。その一方で、アルキル化剤の累積曝露が増えるため、二次悪性腫瘍が心配されていました。

**ナオ**: 結果は安心できるものでしたか。

**マキ先生**: 中央値9.3年の追跡で、二次がんは27例、1.7%でした。8年累積発生率は1.3%です。維持療法なしでは1081例中17例、1.6%、ありでは486例中9例、1.9%で、有意差はありませんでした。

**ナオ**: 何が二次がんに関係していたのでしょう。

**マキ先生**: 27例のうち8例にがん素因症候群があり、Li-Fraumeni症候群が6例、神経線維腫症1型が2例でした。骨肉腫が最も多く、20例は二次がんの前に放射線治療を受けていました。遺伝的素因と放射線の影響が大きいという解釈です。

**ナオ**: ただ、追跡期間はまだ限られますよね。

**マキ先生**: その通りです。晩期に出る二次がんは、さらに長い追跡が必要だと著者らも述べています。

**マキ先生**: 今日のTake Homeを3点。一つ、二次悪性腫瘍は1.7%と低頻度。二つ、維持療法の有無で発生率に差はなく、1.9%対1.6%。三つ、遺伝的素因と放射線歴が重要で、リスクに応じたサバイバーシップ診療が支持されます。

**ナオ**: 最後の3本目です。ブラッド・ネオプラジア誌、思春期・若年成人、AYAの急性リンパ性白血病で、移動時間と保険が専門施設での治療に与える影響を調べた論文です。PMIDは4296、0221です。

**マキ先生**: カリフォルニア、ニューヨーク、テキサスのがん登録から、15歳から39歳の4211人を解析しています。AYAは専門がんセンターで治療を受けると成績が良いと報告されていますが、実際に受けられているのかが問いです。

**ナオ**: どのくらいの方が専門センターで治療を受けていたのですか。

**マキ先生**: 全体で54.5%です。州差が大きく、カリフォルニアは61.5%、ニューヨークは60.9%、テキサスは27.3%でした。しかも非専門施設で治療された方の52%は、専門センターのほうが近いか同程度の距離に住んでいました。

**ナオ**: 距離が理由ではないのですね。

**マキ先生**: 州によります。片道の運転時間が長いと専門センター受診のオッズが下がったのはニューヨークだけでした。一方、無保険は3州すべてで、民間保険に比べ低いオッズと関連しました。メディケイド関連はニューヨークとテキサスで関連していました。

**ナオ**: 日本の状況にそのまま当てはめられるものではないですね。

**マキ先生**: はい。米国の制度に基づく観察研究で、因果は言えません。ただ、治療アクセスの格差という視点は、どの国でも考える価値があります。

**マキ先生**: 今日のTake Homeを3点。一つ、専門センターで治療を受けたAYA-ALLは54.5%で州差が大きい。二つ、無保険は3州すべてで専門センター受診の低さと関連。三つ、移動時間の影響はニューヨークのみで、格差は地域や制度で異なります。

**ナオ**: 今週の3本、どれも、亜型や患者背景によって層別して考える、という点で共通していましたね。

**マキ先生**: そうですね。早期反応、遺伝的素因、アクセス。個別化の視点です。出典は概要欄をご覧いただき、診療判断は必ず原著と最新のガイドラインで行ってください。
